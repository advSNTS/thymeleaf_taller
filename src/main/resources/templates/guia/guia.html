Guía de Instalación

1. Clonar el Repositorio

El primer paso es obtener el código fuente del proyecto. Abre tu terminal y ejecuta el siguiente comando para clonar el repositorio oficial:

git clone https://github.com/advSNTS/thymeleaf_taller

2. Prerrequisitos

Para asegurar que la aplicación funcione en cualquier entorno sin conflictos de dependencias, utilizamos Docker. Asegúrate de tener instalado y ejecutándose Docker Desktop o Docker Engine en tu sistema antes de continuar.

3. Despliegue con Docker

Una vez dentro de la carpeta del proyecto, sigue estos pasos para construir y levantar el contenedor:

A. Construir la imagen:

docker build -t taller .

B. Ejecutar el contenedor:

docker run -p 8080:8080 taller

Esto mapeará el puerto 8080 de tu máquina local al puerto del contenedor.

4. Acceso a la Base de Datos (H2)

La aplicación utiliza una base de datos H2 en memoria para facilitar las pruebas. Puedes acceder a la consola de administración una vez la aplicación esté corriendo en:
http://localhost:8080/h2-console

Importante: Para conectar correctamente, asegúrate de colocar la siguiente configuración en el campo JDBC URL:

jdbc:h2:file:/app/data/testdb
