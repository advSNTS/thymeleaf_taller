Glosario

Thymeleaf

Thymeleaf es un motor de plantillas Java que permite generar vistas HTML dinámicas integradas con Spring Boot.

Spring Boot

Framework de Java que permite crear aplicaciones web rápido sin configurar todo a mano. Levanta un servidor web interno (Tomcat) y conecta controllers, HTML y CSS.

Servidor (Tomcat)

Programa que escucha peticiones HTTP.
1. Se ejecuta en localhost
2. Usa un puerto (por defecto 8080)
3. Spring Boot lo levanta automáticamente

Docker

Plataforma que permite ejecutar aplicaciones junto con todas sus dependencias en contenedores.

Imagen

Plantilla base que contiene todo lo necesario para crear un contenedor.
