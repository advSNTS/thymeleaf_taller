Resumen del proyecto

Esta wiki es un espacio de documentación para el proyecto de desarrollo web. Aquí encontrarás información sobre el proyecto su estructura, y cómo contribuir al mismo. La finalidad del proyecto es representar y visualizar la ejecución de procesos, utilizando diferentes tecnologias y herramientas vistas a lo largo del curso.

Objetivo del sistema

El sistema busca simular y visualizar la ejecución de procesos en un entorno controlado, permitiendo comprender conceptos como concurrencia, planificación y uso de recursos del sistema.

Tecnologias utilizadas

Usamos thymeleaf como motor de plantillas para generar las páginas web dinámicamente. Además, utilizamos HTML y CSS para el diseño y la estructura de las páginas. Posteriormente, se integrará JavaScript para mejorar la interactividad y la experiencia del usuario en el sitio web. Se actualizara la wiki con la información sobre las tecnologías utilizadas a medida que se vayan implementando en el proyecto.

HTML CSS JavaScript Docker Thymeleaf

Arquitectura general

  • Frontend con Thymeleaf
  • Persistencia en Java JPA
  • Contenerización con Docker
